# xCiPiY

## Project Update – AlanRang Private Stable Roadmap

این Repository به عنوان محل نگهداری مستندات، وضعیت توسعه و برنامه‌های آینده استفاده می‌شود.

## هدف اصلی AlanRang

ساخت یک نسخه مستقل و پایدار از AlanRang با اهداف زیر:

- بازسازی اصولی برنامه بدون Patch و فایل‌های موقت
- حفظ قابلیت‌ها و تجربه نسخه اصلی
- ساخت نسخه مستقل با کلید امضای جداگانه
- شروع چرخه اطلاعات جدید از بهار ۱۴۰۵
- پشتیبانی از سال‌های ۱۴۰۶، ۱۴۰۷ و سال‌های آینده
- ایجاد معماری قابل توسعه برای استفاده طولانی‌مدت

## خلاصه فعالیت‌های انجام‌شده

- بررسی تفاوت نسخه اصلی APK و نسخه‌های بازسازی‌شده
- تمرکز روی حذف وابستگی‌های موقت و ساختار تمیز
- طراحی ساختار مستقل Native Wrapper + Asset/WebView
- بررسی امنیت ذخیره‌سازی اطلاعات
- طراحی Backup و Restore امن
- مدیریت سال مالی شمسی
- مدیریت مشتری، فاکتور، مالی و اسناد
- بررسی Release Build و Signing Pipeline

## موارد برنامه‌ریزی‌شده برای آینده

موارد زیر به عنوان Future Update ثبت می‌شوند:

- تکمیل Release Signing نهایی
- Verify امضای APK
- تست نصب واقعی روی دستگاه
- تهیه بسته نهایی APK + Source Archive
- مستندسازی کامل فرآیند ساخت و نگهداری

## بررسی تطبیق با اهداف Repository

وضعیت فعلی Repository برای AlanRang:

- مستندات هدف پروژه: اضافه شد
- Roadmap توسعه: اضافه شد
- فایل‌های فنی نهایی پروژه: نیازمند اضافه شدن در مرحله تحویل نهایی
