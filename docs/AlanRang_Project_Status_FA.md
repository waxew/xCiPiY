# AlanRang Project Status

## هدف و چشم‌انداز

هدف این پروژه ایجاد یک نسخه Private Stable از AlanRang است که از نظر ساختار، نگهداری و توسعه مانند یک محصول مستقل مدیریت شود.

## اهداف اصلی

1. نسخه جدید مستقل از نسخه قبلی باشد.
2. اطلاعات جدید از بهار ۱۴۰۵ شروع شود.
3. امکان ادامه استفاده در سال‌های ۱۴۰۶، ۱۴۰۷ و سال‌های بعد وجود داشته باشد.
4. قابلیت‌های اصلی حذف نشوند.
5. ساختار پروژه قابل توسعه و قابل نگهداری باشد.

## خلاصه کار انجام‌شده

- تحلیل نسخه قبلی AlanRang
- بررسی مشکلات نسخه‌های Build شده
- تمرکز روی جلوگیری از Patch-based development
- طراحی ساختار Clean برای Runtime و Source
- بررسی لایه Native Android
- بررسی Asset/WebView Layer
- طراحی مدیریت مشتری
- طراحی مدیریت مالی
- طراحی فاکتور و اسناد
- طراحی Backup و Restore
- بررسی امنیت اطلاعات
- بررسی فرآیند Release و Signing

## تفاوت با Repository فعلی

موارد زیر در صورت نبودن در Repository باید به عنوان توسعه آینده اضافه شوند:

- سورس کامل نسخه Stable
- APK Release نهایی
- فایل‌های مربوط به امضا
- گزارش تست نهایی
- مستندات Build
- مستندات نگهداری پروژه
